# Stage: Learn - Instant Learning System

> **Mandatory stage after Ship.** Embedded learning moments throughout all stages, consolidated into a mandatory state-machine stage at delivery close.

---

## Core Philosophy

```
Traditional approach:
Develop -> Develop -> Develop -> Learn only after finishing

Hello Dev approach:
Develop -> Learn -> Develop -> Learn -> Finish
  ^_____________________^
       Instant learning throughout
```

---

## Learning Modes

### Mode 1: Embedded Instant Learning

**Every stage includes learning moments:**

```markdown
## [Stage Name] - Learning Moment

### What was learned in this stage?

**Technical knowledge:**
- [ ] Technical point 1
- [ ] Technical point 2

**Thinking patterns:**
- [ ] Thinking approach 1
- [ ] Thinking approach 2

**Improvements for next time:**
- [ ] Improvement point 1
- [ ] Improvement point 2
```

### Mode 2: Decision Review

**Review immediately after each key decision:**

```markdown
## Decision Review

**Decision:** [description]
**Choice:** [option]
**Reasoning:** [why]

**What was learned:**
- [ ] Understood the pros and cons of this technology
- [ ] Learned methods for weighing trade-offs
- [ ] Recognized own knowledge gaps

**Applied to:**
- [ ] Will use this method next time in similar scenarios
```

### Mode 3: Error Learning

**Every error is a learning opportunity:**

```markdown
## Error Learning

**Error:** [description]
**Cause:** [why it went wrong]

**What was learned:**
1. [Knowledge point 1]
2. [Knowledge point 2]

**Prevention methods:**
- [ ] Pay attention to... next time
- [ ] Add checks for...
```

## Learning Triggers

### Automatic Triggers

| Trigger Condition | Learning Type |
|----------|----------|
| Complete a stage | Stage review |
| Make a decision | Decision review |
| Encounter an error | Error learning |
| Solve a hard problem | Experience summary |
| Cycle ends | Skill progress |

### Manual Triggers

| Command | Description |
|------|------|
| `Learned` | Trigger instant learning |
| `Summarize` | Generate experience summary |
| `Skill` | View skill progress |
| `Card` | View knowledge cards |
