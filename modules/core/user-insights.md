# User Behavior Insights

## Core Philosophy

The goal of user behavior insights is to build **correct, professional software**, not to pander to users.

---

## Template

```markdown
## User Behavior Insights

**Pattern observed**: [What users actually do]
**Why it matters**: [Impact on software design]
**Software implication**: [What this means for building professional software]
**Current approach**: [How we handle it now]
**Better approach**: [How we could do it better]

**Feedback received**:
- [Feedback 1 - what they said]
- [Feedback 2 - what they said]

**Analysis**: [User said X but actually means Y]
**Software response**: [How this should change our software]
```

---

## Extraction Timing

- When user provides explicit feedback
- When observing user behavior patterns
- When user says one thing but actually needs another

---

## Application Principle

User behavior insights guide better software design, not making software worse.
